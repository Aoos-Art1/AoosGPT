# التشغيل والتسليم

## بنية الحسابات

البوابات `/login/individual` و`/login/company` و`/login/admin` تستخدم هوية مركزية وجلسات قابلة للإلغاء. فتح بوابة الإدارة لا يمنح دور المدير. أول مدير يُنشأ بأداة تشغيل محلية؛ تسجيل الأفراد والمنشآت يتم بدعوة محددة الصلاحيات والمدة. إنشاء الدعوة لا يرسل رسالة إلى أحد.

بيانات تطبيق SwiftUI الحالية محلية على جهاز المستخدم. قاعدة بيانات الويب مستقلة؛ لم تُنقل كلمات المرور أو حسابات الماك إليها، ولا تعني مزامنة مدير كلمات المرور مزامنة حسابات التطبيق.

## تشغيل الواجهة

تحتاج المعاينة المستقلة إلى Node.js 22.16 أو 24. يتطلب تشغيل الحسابات وحفظ البيانات أيضًا PostgreSQL مدعومًا.

```bash
cd web
npm ci
cp .env.example .env.local
npm run dev
```

افتح `http://localhost:3000/preview/dashboard` للمعاينة الموسومة ببيانات تجريبية. المعاينة لا تمنح جلسة ولا وصولًا إلى قاعدة البيانات. لا تستخدم أسرارًا أو بيانات فعلية فيها. صفحات `/app/*` وواجهات API تتطلب الحساب والصلاحيات الصحيحة.

## تهيئة قاعدة البيانات

أنشئ قاعدة مخصصة واملأ ملف البيئة الخاص:

- `MIGRATION_DATABASE_URL`: حساب يملك إنشاء الجداول ودور التشغيل. يستخدمه مسؤول النشر والأداة فقط.
- `DATABASE_URL`: الحساب `aoos_runtime`، لنفس قاعدة البيانات، بكلمة مرور مستقلة لا تقل عن 24 حرفًا. أداة الترحيل تنشئ الدور وتضبط كلمة مروره؛ التطبيق يرفض استخدام المالك أو دور يتجاوز RLS.
- `APP_ORIGIN`: عنوان الموقع الدقيق، مثل عنوان localhost في التطوير وعنوان HTTPS في الإنتاج.

شغّل الترحيل ثم أنشئ المدير من الطرفية التفاعلية. لا تضع كلمة مرور المستخدم في وسيطات الأوامر أو سجل الطرفية:

```bash
npm run db:migrate
npm run admin:create -- --email YOUR_EMAIL --name YOUR_NAME
```

## الحاويات

ملف Compose يشغّل Caddy أمام التطبيق لتقديم HTTPS. قاعدة البيانات والتطبيق لا ينشران منفذًا عامًا؛ Caddy وحده يستقبل 80 و443. يلزم عنوان DNS فعلي مطابق لـ`APP_ORIGIN` للحصول على الشهادة. استخدم ملف بيئة خاصًا يحتوي كلمات مرور مختلفة مولّدة من أحرف سداسية بطول 24 حرفًا على الأقل، لأن Compose يركّب رابط PostgreSQL منها.

```bash
docker compose --env-file .env.local up -d database
docker compose --env-file .env.local --profile tools run --rm migrate
docker compose --env-file .env.local --profile tools run --rm -it migrate scripts/create-admin.ts --email YOUR_EMAIL --name YOUR_NAME
docker compose --env-file .env.local up -d --build web ingress
```

حساب الترحيل غير موجود في بيئة حاوية الويب. لا تُمرِّر `MIGRATION_DATABASE_URL` إلى العملية التي تخدم المستخدمين. اختبر النسخ الاحتياطي والاستعادة، وحدود حجم الطلب وزمنه في الوكيل العكسي، وفحص `/api/health` قبل الإطلاق. ثبّت صور الإنتاج إلى digests راجعتها في بيئة النشر.

يضبط Caddy الترويسة المخصصة `X-Aoos-Client-IP` إلى عنوان الاتصال الفعلي وحده، ويستبدل أي قيمة مرسلة من العميل باستخدام `header_up`. لذلك يفعّل Compose `TRUST_PROXY_HEADERS=true` لعملية الويب المحجوبة خلفه. في النشر اليدوي لا تفعّل هذا المتغير إلا بعد ضبط وكيل موثوق يستبدل هذه الترويسة بعنوان IP واحد ويمنع الوصول المباشر إلى Next.js. لا تكفي إضافة الترويسة من المتصفح أو فتح منفذ الويب للعامة. راجع [تعديل ترويسات الطلب في Caddy](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy#headers).

تبقى `X-Forwarded-For` متاحة للتمرير الاعتيادي إلى Next.js، لكن محدد محاولات الدخول لا يثق بها ولا بـ`X-Real-IP`؛ قد يضيف Next.js قيمة `X-Forwarded-For` من اتصال المقبس حتى دون وكيل. في الإنتاج، غياب الإعداد أو الترويسة المخصصة، أو احتواؤها على عنوان غير صالح أو عدة عناوين، يرجع `503 PROXY_CONFIGURATION_REQUIRED`. في التطوير فقط يبقى حد محافظ مشترك عند غياب عنوان موثوق.

## حدود السعة الحالية

تسمح هذه النسخة بـ1000 موظف و300 مهمة لكل مساحة، و100 خطاب و100 محادثة لكل مستخدم في المساحة. المعرفة محدودة بـ100 مستند والذاكرة بـ50 عنصرًا. تُفرض الحدود داخل معاملة قبل الحفظ، وتطابق حدود القراءة؛ لا تُقبل سجلات مخفية خارج القوائم. تُراجع توسعة السعة مع تصميم التصفح المرحلي واختبارات الأداء، ولا تؤدي تسمية خطة الاشتراك وحدها إلى رفعها.

## تشغيل «سعود» والصوت

- المحادثة: `AI_API_KEY` و`AI_MODEL` لنموذج متاح في حساب المزوّد. الاتصال الافتراضي OpenAI Responses، مع `store:false`.
- التفريغ الصوتي: `AI_API_KEY` و`AI_TRANSCRIPTION_MODEL` لنموذج يدعم endpoint `/audio/transcriptions`.
- النطق السعودي: `AZURE_SPEECH_KEY` و`AZURE_SPEECH_REGION`. الصوت المهيّأ هو `ar-SA-HamedNeural`.

عدم وجود هذه القيم يظهر حالة غير مفعّلة، ولا ينتج إجابة وهمية. إعداد مفتاح لا يثبت نجاح الخدمة: يجب اختبار استجابة فعلية ونص عربي وتسجيل صوتي بعد الإعداد. لا تُجرى هذه الاختبارات بمفاتيح مستخدم مفترضة أو بإخراج أسراره في السجلات.

التسجيل يبدأ بالنقر؛ يتحول إلى PCM WAV أحادي 16kHz لمدة أقصاها 60 ثانية، ويظهر النص للمراجعة قبل إرساله. الصوت الناتج موسوم بأنه مولّد. لا تُحفظ التسجيلات الصوتية في قاعدة البيانات.

## المعرفة والذاكرة

تُجزّأ نصوص مستندات المنشأة ويُبحث داخل نطاق المنشأة باسترجاع نصي مرتب. هذه النسخة لا تدّعي استخدام بحث متجهي أو إعادة تدريب النموذج. للمستخدم محادثاته وذكرياته الشخصية؛ إيقاف الذاكرة يمنع استرجاعها، والحذف يزيل السجل. لا تُسترجع بيانات منشأة أخرى.

المراجع المرفوعة ليست توثيقًا حكوميًا تلقائيًا. تفاصيل الأنظمة والرسوم والمواعيد تحتاج مصدرًا مناسبًا ومراجعة حداثته؛ دليل المنصات روابط رسمية، ولا ينفذ معاملة أو اتصالًا بحساب حكومي.

## الحاسبات والفحص

تكلفة التوظيف تقدير يعتمد على مدخلات المستخدم، ونسبة المساهمة تُطبّق على الراتب الأساسي كما تظهر الواجهة. تقسيم الراتب يستخدم عدد أيام الفترة الذي يختاره المستخدم. النتائج ليست قاعدة نظامية عامة أو إقرارًا بصحة احتساب مستحقات حالة محددة.

قائمة الالتزام هي مراجعة ذاتية لاكتمال الأدلة، وليست شهادة امتثال أو تصنيف نطاقات أو بديلًا عن مراجعة الجهات المختصة.

## التحقق

```bash
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:production
```

تشغّل اختبارات المتصفح بناء `standalone` السابق خلف HTTPS محلي بشهادة اختبار مؤقتة، وتتطلب OpenSSL وChromium. قبول هذه الشهادة مقصور على سياق Playwright المؤقت. اختبار وضع الإنتاج المنفصل يفحص الخادم الداخلي وسياسات الكوكيز والأصل والترويسات؛ لا يمثل اختبارًا لشهادة عامة أو لتشغيل Caddy داخل Docker. تُسجل نتائج التشغيل الفعلية وما لم يُختبر في `VALIDATION.md`.
