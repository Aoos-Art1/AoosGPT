# تقرير التحقق من منصة سعود

## حدود النتيجة

هذا التقرير يوثق تنفيذ مشروع الويب داخل AoosGPT والتحقق منه ببيانات اصطناعية وقواعد مؤقتة. تطبيقات SwiftUI وحساباتها المحلية مستقلة عن قاعدة بيانات الويب. نجاح هذه الفحوص لا يعني إنشاء حساب مشغّل فعلي أو ربط مزود ذكاء اصطناعي أو نشر خدمة عامة.

## الفحوص المنفذة

| الفحص | النتيجة | ما يثبته |
| --- | --- | --- |
| ESLint | ناجح دون أخطاء أو تحذيرات في المصدر | اتساق الشيفرة وقواعد React/Next.js المطبقة. |
| TypeScript | ناجح | توافق العقود والأنواع ومسارات التطبيق. |
| Vitest | **104 اختبارات ناجحة في 10 ملفات** | المصادقة وRLS والعزل والذاكرة وترتيب الرسائل واسترجاع المصادر والصوت والحاسبات ومعالجة أخطاء الاتصال. |
| بناء Next.js | ناجح في بيئة التطوير وعلى Mac | إنشاء نسخة `standalone` وتجهيز ملفاتها الثابتة. |
| PostgreSQL فعلي + خادم الإنتاج | **22 مجموعة سيناريوهات ناجحة** | الترحيلات 001–003، الدخول والدعوات وإلغاؤها، الأدوار، الفصل بين الشركات، CRUD، سحب الجلسات، ترتيب الرسائل، وخصائص كوكي الإنتاج وترويسة العميل الموثوق. |

تستخدم فحوص SQL كلًا من PGlite ومحرك PostgreSQL مؤقت عبر `embedded-postgres`. تُنشأ كلمات المرور والحسابات الاختبارية عشوائيًا، ويُحذف عنقود الاختبار عند الانتهاء. لا تُستخدم قاعدة المشغّل أو مفاتيح مزود حي.

## نقاط راجعها المدقق المستقل

- منع إعادة إدخال تفضيل محذوف عبر رد قديم: حدود مراجعة للذاكرة وسياق جديد عند تغييرها، ورفض الرد المعلق إذا تغيّرت المراجعة.
- صحة ترحيل البيانات تحت مالك جداول محدود الصلاحية، واستعادة `FORCE ROW LEVEL SECURITY` قبل اكتمال المعاملة.
- ترتيب الرسائل بواسطة رقم تسلسلي تولّده القاعدة، ومنع دور التشغيل من تزويره أو إعادة تعيينه.
- تطابق وسوم المراجع في الإجابة وبطاقات المصادر.
- إلغاء طلبات المحادثة والتفريغ والنطق عند الانتقال أو بدء محادثة جديدة، وإيقاف الميكروفون والتشغيل السابق.
- تصحيح دعوات الشركات الموجودة، وقفل قبول الدعوة وإلغائها لمنع تعارض النتائج.
- بحث وتصفح إداري يصل إلى سجلات تتجاوز 500، وحدود ذرية للسجلات تطابق سعة قوائم مساحة العمل.
- فصل بوابة الإدارة عن صلاحيات المستخدم، ومنع تعديل دور مدير المنصة من دور قاعدة بيانات التشغيل.
- إصلاح تمدد عرض الجوال بسبب عنوان جدول مخفي مطلق الموضع، مع الحفاظ على التمرير الأفقي داخل الجدول وإخفاء القائمة المغلقة عن التركيز.
- توحيد العرض الأول عند تقليل الحركة، وعرض تاريخ السعودية بعد hydration دون ربط التاريخ بيوم البناء.
- تعريف أيقونة المتصفح صراحةً بعد كشف Chromium الكامل عن طلب `favicon.ico` غير موجود، وفحص تحميل ملف SVG مع تسجيل مسار موارد الواجهة الفاشلة دون تجاهل أخطائها.

المراجعة والاختبارات تغطي الحالات المذكورة؛ لا تمثل شهادة خلو مطلق من العيوب.

## طريقة فحص المتصفح والإنتاج

تختبر Playwright نسخة البناء المستقلة عبر HTTPS محلي بشهادة مؤقتة يقبلها سياق الاختبار فقط، على قياسي كمبيوتر وPixel 7. تُفحص الأقسام العشرة، والأخطاء البرمجية وأخطاء hydration، وعرض المحتوى مقارنة بعرض الجهاز المحدد، والبحث باللمس ولوحة المفاتيح، وحفظ الموظفين والخطابات والذاكرة، والدعوات الإدارية.

تُحفظ لقطات الكمبيوتر باستخدام نافذة متصفح بارتفاع الصفحة ثم يُستعاد القياس الأصلي. يعالج هذا خلل تصوير `fullPage` في Chromium كان يخفي رسم محتويات القائمة الثابتة داخل الصورة فقط؛ تأكد ظهور الروابط العشرة ونجاح التنقل بنقرات عادية في المتصفح.

اختبار الإنتاج المنفصل يصل إلى خادم Next.js الداخلي مع أصل HTTPS مضبوط وترويسة `X-Aoos-Client-IP`. يتحقق من `Secure` و`HttpOnly` و`SameSite=Lax` وبادئة `__Host-`، ويرفض غياب الترويسة الموثوقة أو تعدد عناوينها. إعداد Caddy يستبدل الترويسة من الاتصال الفعلي ويحجب منفذ الويب عن الوصول العام في Compose.

## ما يتطلب تحقق التشغيل الحي

1. تزويد حساب تشغيل حقيقي لقاعدة PostgreSQL، وتشغيل النسخ الاحتياطي والاستعادة وسياسة الاحتفاظ على الاستضافة المختارة.
2. إنشاء المدير الأول ببيانات المشغّل عبر الأداة المحلية؛ لم يُنشأ حساب افتراضي أو تُنقل كلمات مرور الأجهزة.
3. إدخال مفاتيح ونماذج مزودي المحادثة والتفريغ والنطق، ثم اختبار الاستجابة والصوت والميكروفون فعليًا ومراجعة شروط معالجة البيانات.
4. تشغيل حاويات Docker/Caddy على الخادم المقصود والتحقق من DNS وشهادة HTTPS العامة؛ لم يُنفّذ نشر عام في هذه الجولة.
5. الخطط تصنيفات إدارية، وقائمة الالتزام مراجعة ذاتية، والدليل روابط رسمية. لا توجد بوابة دفع أو إرسال دعوات بالبريد أو معاملات حكومية مدمجة.

## إعادة التشغيل

```bash
npm ci
npm run check
npx playwright install chromium
npm run test:e2e
npm run test:production
npm audit --omit=dev
```

يحتاج اختبار المتصفح إلى OpenSSL وChromium. توجد نسخة CI في `../../.github/workflows/web-platform.yml`، وتُراجع حالة تشغيلها على GitHub بصورة مستقلة عن نتائج الفحوص المحلية الواردة هنا.
