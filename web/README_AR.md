# AoosGPT للويب — دليل الاستخدام والتشغيل

**AoosGPT** مساحة عربية لإدارة أعمال المنشأة، والمستندات، والمتابعة، والمحادثة مع مساعد يستخدم المعرفة المضافة إلى المساحة. هذا المجلد يحتوي تطبيق ويب مستقلًا داخل مستودع AoosGPT. يبقى تطبيق SwiftUI للماك والآيفون في المجلد الأب، وتبقى حساباته وبياناته المحلية منفصلة. لم تُرحّل حسابات الأجهزة أو كلمات مرورها إلى قاعدة بيانات الويب، ولا توجد مزامنة تلقائية بين العميلين. تعليمات التطبيق الأصلي موجودة في [دليله العربي](../README_AR.md).

## جرّب الواجهة دون قاعدة بيانات

تحتاج إلى Node.js 22.16 أو إصدار مدعوم من سلسلة 24. من جذر المستودع:

```bash
cd web
npm ci
npm run dev
```

افتح [المعاينة المحلية](http://localhost:3000/preview/dashboard). لا تحتاج المعاينة إلى PostgreSQL أو حساب أو مفتاح ذكاء اصطناعي. بياناتها توضيحية وموسومة بذلك، ويمكن تجربة الأزرار والنماذج والتعديلات المؤقتة. تعود البيانات الأصلية عند إعادة تحميل الصفحة. لا تنشئ المعاينة جلسة دخول، ولا ترسل محادثة إلى نموذج، ولا تحفظ تعديلاتها في قاعدة بيانات العملاء.

الصفحة `/` تقدّم المنتج وتتيح الانتقال إلى المعاينة أو تسجيل الدخول. المسارات تحت `/app` مخصّصة للحسابات الفعلية، وتتحقق من الجلسة والعضوية على الخادم.

## أقسام مساحة العمل

كل مسار في الجدول له نسخة توضيحية باستبدال `/app` بـ`/preview`:

| القسم | المسار | الاستخدام |
| --- | --- | --- |
| لوحة التحكم | `/app/dashboard` | مؤشرات من البيانات المدخلة، ومهام قابلة للإضافة والإنجاز والحذف. |
| المساعد الذكي | `/app/assistant` | محادثة حقيقية عند تهيئة المزود، مع مراجع وصوت اختياري. |
| سجل المحادثات | `/app/history` | البحث في محادثات المستخدم وفتحها وحذفها. |
| الخطابات | `/app/letters` | إنشاء مسودات وتحريرها وحفظها وتنزيل نصها وطباعتها. |
| الحاسبات | `/app/calculators` | حساب نسبة من مبلغ أو أجر عن أيام بمدخلات معلنة. |
| متابعة الامتثال | `/app/compliance` | قائمة مراجعة ذاتية مع روابط رسمية وإضافة مهام متابعة. |
| التوظيف والتكاليف | `/app/hiring` | تقدير تكلفة الموظف والسنة الأولى وفق الأرقام التي تدخلها. |
| المنصات الحكومية | `/app/platforms` | دليل قابل للبحث والتصفية، يفتح مواقع الجهات الرسمية. |
| بيانات المنشأة | `/app/company` | تحديث الملف الأساسي وإدارة الموظفين بحسب الصلاحية. |
| الإعدادات | `/app/settings` | معرفة المنشأة والذاكرة والسعة وتنزيل البيانات المعروضة. |

الحاسبات لا تفترض نسبًا أو رسومًا حكومية. قائمة المتابعة ليست شهادة امتثال أو تصنيف نطاقات، ونسبة السعوديين وصف لبيانات الفريق المدخلة. روابط المنصات لا تعني تكاملًا معها أو تنفيذ معاملات حكومية من خلال AoosGPT.

## ثلاث بوابات وصلاحيات فعلية

تتوفر بوابات الأفراد والشركات والإدارة في `/login`، وكذلك عبر `/login/individual` و`/login/company` و`/login/admin`. اختيار البوابة لا يمنح صلاحية؛ الخادم يتحقق من نوع المساحة وعضوية الحساب ودوره. عند تعدد عضويات الشركة، يختار المستخدم المساحة التي يريد دخولها.

تعتمد مساحة العمل أدوار المالك، والمسؤول، والعضو، والمشاهد. إدارة الملف والموظفين والمعرفة تحتاج صلاحية إدارة المساحة؛ العضو يستطيع استخدام عمليات الكتابة المسموحة، والمشاهد للقراءة. دور `super_admin` منفصل عن هذه الأدوار، ويخص مشغّل المنصة البشري. لا يستطيع المساعد منح صلاحيات أو إنشاء مدير.

الانضمام بالدعوة عبر `/invite?token=...`، دون تسجيل عام مفتوح. إنشاء الدعوة يعيد رابطًا ليشاركه المسؤول مع الشخص المقصود، **ولا يرسل بريدًا إلكترونيًا تلقائيًا**. إذا كان للمدعو حساب، يستخدم كلمة مروره الحالية؛ قبول الدعوة لا يعيد تعيينها. الحساب الجديد يحتاج كلمة مرور من ١٥ إلى ١٢٨ حرفًا.

حقول الدخول تدعم إشارات التعبئة التلقائية المعتادة. يمكن استخدام مدير كلمات المرور الذي يختاره المستخدم بحسب إعدادات جهازه ومتصفحه. لا يضمن التطبيق حفظًا تلقائيًا في Apple Passwords، ولا يستورد كلمات مرور تطبيق الماك. راجع [إرشادات التعبئة التلقائية من Apple](https://support.apple.com/guide/iphone/automatically-fill-in-strong-passwords-iphf9219d8c9/ios).

## ما تنفذه الخلفية

تُحفظ بيانات المساحة في PostgreSQL عبر واجهات API تتحقق من المدخلات والصلاحيات. الموظفون والمهام ومعرفة المنشأة ضمن نطاق المساحة، بينما الخطابات والمحادثات والذاكرة مرتبطة أيضًا بالمستخدم. تستخدم الحسابات تجزئة كلمات المرور بـ`scrypt` وجلسات قابلة للإلغاء بملفات ارتباط `httpOnly`، مع تحقق من مصدر طلبات التعديل وحدود للطلبات.

يجمع العزل بين التحقق الخادمي وسياسات RLS في قاعدة البيانات، ودور تشغيل محدود منفصل عن حساب الترحيل. لوحة `/admin` تعرض بيانات إدارية للحسابات والمساحات والدعوات، وتدعم إدارة الحالة والخطط؛ لا تعرض محتوى محادثات العملاء. أسماء الخطط تصنيفات إدارية حاليًا، **وليست بوابة دفع أو نظام فوترة**، ولا ترفع السعة بمجرد تغيير الاسم.

## الذكاء الاصطناعي والمعرفة والصوت

اسم المنصة والمساعد **AoosGPT**. من صفحة المساعد يمكن اختيار المجال تلقائيًا أو يدويًا، ثم تحديد «إجابة مباشرة» أو «اشرح ودرّبني». استعراض المهارات يضع مثالًا في المسودة للمراجعة قبل الإرسال. ينطبق الاختيار على الرد التالي، ولا ينشئ إعدادًا دائمًا للحساب.

تضم المنهجيات الست المرفقة تنسيق العلاقات الحكومية، والتواصل مع المستفيدين، والالتزام العمالي، والإقامات والتأشيرات، والتراخيص والاستثمار، وتحليل المستجدات. أُكملت بثلاثة مسارات مذكورة في المرفقات: البلدية والسلامة والصحة، وحل الحالات والتصعيد، ومراجعة المصادر والأدلة. يجمع التوجيه الاختصاصات المطابقة للسؤال، ويحافظ على فصل معلومات المصدر عن الاستنتاج والأسئلة الناقصة. راجع [تقرير المهارات والمشروع المرجعي](docs/SKILLS_REVIEW.md).

وضع التعليم يطلب شرحًا ومثالًا افتراضيًا وتمرينًا ثم تغذية راجعة على المحاولة. المهارات منهجيات مرتبطة بطلب النموذج؛ لا تضيف وحدها بحثًا حيًا أو رصدًا تلقائيًا أو تنفيذ معاملات. تحتاج التفاصيل الحكومية المتغيرة إلى مادة مناسبة والتحقق من سريانها لدى الجهة.

تبقى مفاتيح المزود في الخادم. تهيئة الخصائص اختيارية ومستقلة عن تشغيل إدارة المنشأة:

| الإعداد | المتغيرات المطلوبة |
| --- | --- |
| المحادثة | `AI_API_KEY` و`AI_MODEL` لنموذج متوافق مع Responses API. |
| تفريغ الصوت | `AI_API_KEY` و`AI_TRANSCRIPTION_MODEL`. |
| النطق | `AZURE_SPEECH_KEY` و`AZURE_SPEECH_REGION`؛ الصوت المحدد `ar-SA-HamedNeural`. |
| عنوان مزود بديل | `AI_BASE_URL` اختياري؛ يلزم توافق الواجهات التي تستدعيها الشيفرة. |

غياب الإعدادات يظهر بوضوح دون ردود مصطنعة. ظهور «الخدمة مهيأة» لا يثبت صلاحية المفتاح أو نجاح المزود. لم يُجر حتى الآن تحقق حي بالمزود ضمن هذا التسليم؛ اختبار المحادثة والتفريغ والنطق بحساب المشغّل خطوة مستقلة.

استرجاع المعرفة نصي مع ترتيب المقاطع بحسب تطابق الكلمات، داخل نطاق المنشأة. لا يستخدم بحثًا متجهيًا أو تدريبًا للنموذج. إضافة رابط مصدر لا تجلب الصفحة تلقائيًا؛ النص المضاف هو المادة المرجعية، ووسوم المصادر تربط الإجابة بالمقاطع المستخدمة دون إثبات رسميتها أو حداثتها.

الذاكرة اختيارية، ويُضاف التفضيل بطلب صريح ويمكن تعديله وحذفه. تغيير التفضيلات أو تفعيل الذاكرة يبدأ سياق نموذج جديدًا للمستخدم داخل المساحة؛ تبقى الرسائل السابقة ظاهرة، لكنها لا تُعاد ضمن السياق الجديد. حذف المحادثة إجراء مستقل. لا يمكن استرجاع مدخل أُرسل مسبقًا إلى المزود. تستخدم طلبات OpenAI خيار `store:false`، دون ادعاء انعدام الاحتفاظ لدى المزود؛ راجع [ضوابط البيانات الرسمية](https://developers.openai.com/api/docs/guides/your-data).

يبدأ التسجيل بالنقر ويتوقف خلال حد ٦٠ ثانية، ويظهر التفريغ للمراجعة قبل الإرسال. الصوت الناتج موسوم بأنه اصطناعي. تدعم الشيفرة صوتًا عربيًا سعوديًا وفق [مرجع Azure للأصوات](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=text-to-speech).

## تشغيل الحسابات والنشر

اتبع [دليل التشغيل التفصيلي](docs/OPERATIONS.md). انسخ `.env.example` إلى ملف خاص، واضبط `APP_ORIGIN` و`DATABASE_URL` و`MIGRATION_DATABASE_URL`. الأخير لحساب التهيئة فقط، ولا يُمرّر إلى عملية الويب التي تخدم المستخدمين.

بعد تجهيز قاعدة البيانات، يشغّل المسؤول:

```bash
npm run db:migrate
npm run admin:create -- --email YOUR_EMAIL --name YOUR_NAME
```

تُطلب كلمة مرور المدير تفاعليًا؛ لا توضع ضمن وسيطات الأمر. هذا إجراء للمشغّل المخوّل، ولا ينشئ التطبيق حساب مدير افتراضيًا. يتضمن `compose.yaml` خدمات PostgreSQL والترحيل والويب وCaddy لتقديم HTTPS. اتبع تسلسل Compose في دليل التشغيل، مع نطاق صحيح وإعداد الوكيل والنسخ الاحتياطي والاستعادة. تشغيل الواجهة محليًا أو نجاح البناء لا يثبت اكتمال النشر العام أو موقع استضافة البيانات.

## للمطوّر والتحقق

البنية: Next.js App Router وReact وTypeScript وTailwind، وزر قابل لإعادة الاستخدام بنمط [shadcn/ui مع Radix](https://ui.shadcn.com/docs/components/radix/button) وCVA، وFramer Motion. الواجهة RTL، وتضم خطي IBM Plex Sans Arabic وTajawal محليًا. توجد العقود في `src/lib/contracts.ts`، والمكونات في `src/components`، والمنطق الخادمي في `src/lib/server`، والترحيلات في `db/migrations`. راجع [خطة البنية](docs/ARCHITECTURE.md)، و[المصادقة في Next.js](https://nextjs.org/docs/app/guides/authentication)، و[سياسات PostgreSQL](https://www.postgresql.org/docs/current/ddl-rowsecurity.html).

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run test:integration
npx playwright install chromium
npm run test:e2e
npm run test:production
```

يشغّل اختبار التكامل قاعدة PostgreSQL مؤقتة منفصلة. يشغّل `test:e2e` البناء السابق في وضع الإنتاج خلف HTTPS محلي بشهادة اختبار مؤقتة يقبلها متصفح الاختبار وحده؛ ويتطلب OpenSSL وChromium. لا يستخدم اختبار المتصفح خادم إعادة التحميل أثناء التطوير. يفحص `test:production` الكوكيز وسياسة الأصل والوكيل عبر الاتصال الداخلي. لا تثبت هذه الاختبارات إصدار شهادة عامة أو تشغيل حاويات الإنتاج. تُسجّل النتائج الفعلية والقيود في [تقرير التحقق](docs/VALIDATION.md). تفاصيل المزود والذاكرة في [دليل خدمة الذكاء الاصطناعي](src/lib/server/ai/README.md).

يوجد سير تحقق آلي في `.github/workflows/web-platform.yml` يستخدم Node.js 24 ويشغّل التحليل وفحص الأنواع والاختبارات والبناء وفحوص المتصفح ووضع الإنتاج. لا يحتاج أسرار GitHub أو بيانات عميل، ولا يجري اتصالات حيّة بمزوّدي الذكاء الاصطناعي.
